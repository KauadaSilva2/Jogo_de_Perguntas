# Jogo_de_Perguntas

# 🎮 Jogo de Perguntas em Java

Um jogo simples de perguntas e respostas desenvolvido em **Java** para praticar os fundamentos da linguagem e lógica de programação.

## 📌 Sobre o projeto

O jogador informa seu nome e responde a uma sequência de perguntas de múltipla escolha.

Ao final, o programa apresenta:

* ✅ Quantidade de acertos
* ❌ Quantidade de erros
* 📊 Total de perguntas respondidas
* 🏆 Resultado final de acordo com a pontuação

## 🧠 Conceitos praticados

Neste projeto foram utilizados conceitos básicos de Java, como:

* `Scanner` para entrada de dados
* Variáveis
* `String`
* Estruturas condicionais `if/else`
* Estrutura `switch/case`
* Estrutura de repetição `do/while`
* Operadores relacionais
* Incremento de variáveis
* Contagem de acertos e erros

## ❓ Perguntas

Atualmente, o jogo possui 3 perguntas:

1. Qual é a capital do Brasil?
2. Quem era Júlio César?
3. Em que ano o Flamengo foi treinado pelo JJ?

## ▶️ Como executar

### Pré-requisitos

É necessário ter o **Java (JDK)** instalado no computador.

### Executando pelo terminal

Clone o repositório:

```bash
git clone https://github.com/KauadaSilva2/Jogo_de_Perguntas.git
```

Entre na pasta:

```bash
cd Jogo_de_Perguntas
```

Compile o programa:

```bash
javac Jogo_de_perguntas.java
```

Execute:

```bash
java Jogo_de_perguntas
```

## 📷 Funcionamento

O jogador informa seu nome e escolhe uma alternativa para cada pergunta.

Ao final, o programa mostra sua pontuação e informa se atingiu a quantidade mínima de acertos.
